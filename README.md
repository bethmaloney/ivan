Iter Vehemens ad Necem
======================

[![Play in your browser](https://img.shields.io/badge/play-playivan.pages.dev-8b0000)](https://playivan.pages.dev/)

Iter Vehemens ad Necem (IVAN) is a graphical roguelike game, featuring advanced
bodypart and material handling, multi-colored lighting and, above all, deep
gameplay.

This is a fork of [Attnam/ivan](https://github.com/Attnam/ivan), itself a fan
continuation of the original IVAN by members of Attnam.com. It turns IVAN into a
browser game: the C++ game logic is compiled to WebAssembly, and the graphics,
sound, input and UI are being rewritten as JavaScript on the page.

**The browser is the only build that ships** — play it at
[playivan.pages.dev](https://playivan.pages.dev). The native build is still here,
and still the reference the tests measure the WASM one against, but it is not
released.
